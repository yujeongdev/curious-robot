# Reality plant와 belief model 사이에는 관측만 흐른다

> 인접 문서: [아키텍처](../architecture.md) · [Agent Lab 목표 감사](../agent-lab-goal-audit.md)

2026-10-21 작성. 범위: simulated reality를 물리 공간 대체물로 쓰는 동안에도
real-to-sim 경계를 보존하는 실행 계약. 기준: 이 문서와 함께 배포되는 코드 revision.

## 1. 네 소유자

```text
Scenario secret → Reality plant → Observations → Experiments/SysID
                                             ↓
                                      Posterior belief
                                             ↓
                                      Belief simulation

Evaluator ← terminal result + scenario secret
```

- Reality plant만 randomized mass/material과 Newton 내부 state를 소유한다.
- Agent는 robot command를 보내고 joint/FK, camera pose, native contact force만 받는다.
- SysID는 observation/evidence만 입력으로 받으며 Newton model이나 secret을 받지 않는다.
- Belief simulation은 posterior와 공개된 scene geometry/numerical config로 새로 생성한다.
- Evaluator만 terminal 이후 posterior와 secret을 비교한다.

## 2. 값의 세 종류

| 종류 | 예 | 저장 위치 | 변경 방법 |
| --- | --- | --- | --- |
| 연구 가정 | cube geometry, SI 단위, 중력 방향 | `WorldConfig`, capability docs | 새 protocol/schema revision |
| 실험 protocol | 접근 거리, 속도, 힘 한계, breakaway 조건 | `configs/physical_experiments.json`, run artifact | config 변경 및 재실행 |
| 학습 변수 | mass, effective breakaway/sliding resistance, CI | evidence → `PhysicalBelief` → `belief_simulation_config.json` | robot 실험과 SysID만 |

학습 변수의 episode 값은 소스 코드 literal로 넣지 않는다. Truth 값은 controller,
planner, public event, experiment report에 전달하지 않는다.
각 run의 `value_provenance.json`은 이 분류와 실제 artifact 간 dataflow를
machine-readable하게 고정한다. 따라서 protocol을 바꾸면 새 protocol snapshot이,
실험 결과가 바뀌면 새 posterior와 belief simulation config가 생성된다.

## 3. 현재 물리 producer

- Action: Franka joint targets generated by IK.
- Contact: MuJoCo Warp rigid contact owned by `SolverMuJoCo`.
- Force: Newton 1.7 `CONTACT_F` observable aggregated by `SensorContact` for
  robot-tool ↔ cube pairs.
- Pose: simulated camera-equivalent cube pose observation with configured noise.
- Belief: independent Newton allocation using posterior estimates.

`state.body_f[cube]` is reserved only for the private velocity-dependent material-law
correction. No public action accepts a cube force and no sensor echoes a command as a
measurement.

## 4. Honest limits

- The current validated physical experiment is a robot-mounted pusher probe. Bilateral
  gripper lift has not passed its acceptance gate, so mass remains prior/unidentified.
- Newton's native material has one Coulomb coefficient; separate static/dynamic values
  are effective model parameters and structured residuals are reported.
- `SensorContact` supplies linear contact force, not a complete strain-gauge wrist moment.
- A future hardware backend must implement the same command/observation contract; SysID
  and belief construction must not gain a simulator-specific truth channel.
